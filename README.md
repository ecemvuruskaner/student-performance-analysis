# Student Performance Analysis

## Overview
Predicting student pass/fail outcomes using machine learning.

## Dataset
500 students, 10 features including study habits, attendance, and scores.

## Methods
- Exploratory Data Analysis
- Correlation Analysis
- Logistic Regression, Decision Tree, Random Forest

## Key Findings
- Study hours is the strongest predictor of academic success (r=0.80)
- Logistic Regression achieved 87% accuracy

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn
